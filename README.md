# KPI Dashboard

## 📝 概要 (Overview)

売上・営業・工数・請求などのビジネス重要指標を、ひとつの画面でシンプルに管理・可視化するためのダッシュボードアプリケーションです。

複雑な設定やバックエンドサーバーを必要とせず、ブラウザ上で即座に利用を開始できる手軽さが特徴です。

**🌐 Live Demo**: [https://kpi-dashboard-ico.vercel.app/](https://kpi-dashboard-ico.vercel.app/)

## ✨ 特徴 (Features)

- **オールインワン管理**  
  売上、営業進捗、プロジェクト工数、請求ステータスなど、分散しがちな指標を統合的にモニタリング

- **完全ローカル動作 (Serverless)**  
  入力されたデータはすべて利用しているデバイスの LocalStorage に保存されます。外部サーバーとの通信がないため、セキュアかつ高速に動作し、バックエンドの構築も不要です

- **クリーンなUI設計**  
  日々の業務でストレスなく数値を把握できるよう、視認性と操作性を重視した直感的なインターフェースを提供

## 🛠 技術スタック (Tech Stack)

| カテゴリ | 技術 |
|---------|------|
| **Framework** | Next.js / React |
| **Styling** | Tailwind CSS |
| **State Management** | Zustand |
| **Storage** | LocalStorage API |
| **Deployment** | Vercel |

## 🚀 使い方 (How to Use)

1. ブラウザで [ダッシュボードURL](https://kpi-dashboard-ico.vercel.app/) にアクセスします
2. 画面の指示に従い、各項目の数値を入力または更新します
3. データは自動的にブラウザに保存されるため、ページをリロードしたり次回アクセスした際も状態が保持されます

> **※注意**  
> キャッシュのクリアや別ブラウザ・別デバイスからのアクセス時はデータが引き継がれません。
